# 项目说明文档

## 选题：JATS XML → PDF 智能排版

### 一、我们要做什么

把学术期刊的标准 JATS XML 数据文件，自动渲染成排版精美的 PDF 论文。

### 二、核心流水线（Pipeline）

```
┌──────────┐    ┌──────────┐    ┌──────────┐
│ JATS XML │ → │ 解析器   │ → │ 渲染器   │ → PDF
│ 输入文件 │    │ Parser   │    │ Renderer │   输出
└──────────┘    └──────────┘    └──────────┘
```

#### 第1步：解析 JATS XML
- 使用 `lxml` 库解析 XML
- 提取：标题、作者、摘要、关键词、章节结构、公式(MathML)、表格、参考文献
- 输出为结构化的 Python `Article` 对象

#### 第2步：渲染 HTML
- 使用 `Jinja2` 模板引擎
- 将 `Article` 对象 + HTML模板 → 完整HTML文档
- 公式使用 MathJax 渲染（在HTML中嵌入MathML/SVG）
- CSS Paged Media 控制排版

#### 第3步：生成 PDF
- 使用 `WeasyPrint` 将 HTML → PDF
- 支持：自动分页、页眉页脚、页码
- 支持单栏/双栏切换
- 嵌入字体和图片

### 三、技术选型理由

| 需求 | 方案 | 理由 |
|------|------|------|
| PDF生成 | WeasyPrint | Python原生，CSS排版灵活 |
| 模板 | Jinja2 | 最成熟的Python模板引擎 |
| XML解析 | lxml | 比标准库快10倍+，支持XPath |
| 公式 | MathJax + MathML | 保留原始语义，渲染质量高 |

### 四、难点与解决思路

#### 难点1：中文排版
- **问题**：WeasyPrint默认不支持中文换行规则
- **方案**：配置Noto Sans/Serif CJK字体，CSS中设置`word-break`和`text-align: justify`

#### 难点2：公式渲染
- **问题**：MathML到PDF的保真渲染
- **方案**：在HTML中用MathJax将MathML渲染为SVG，WeasyPrint保留SVG

#### 难点3：图表浮动定位
- **问题**：图表在图题附近自动定位，避免大片空白
- **方案**：CSS Paged Media的`float`属性和`page-break-inside: avoid`

#### 难点4：单/双栏切换
- **问题**：正文双栏、摘要单栏混排
- **方案**：CSS `column-count` 属性 + `column-span: all`

### 五、文件结构说明

```
期刊大赛/
├── src/parser/jats_parser.py    ← 核心：XML解析 + 数据模型
├── src/templates/article.html   ← HTML模板（Jinja2语法）
├── src/templates/styles.css     ← CSS排版样式
├── src/renderer/html_renderer.py ← Jinja2渲染引擎
├── src/renderer/pdf_renderer.py  ← WeasyPrint PDF生成
├── src/main.py                  ← 命令行入口
├── samples/sample1.xml          ← 示例JATS XML文件
├── tests/                       ← 单元测试
└── docs/                        ← 文档
```
