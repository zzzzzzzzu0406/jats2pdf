# 项目说明文档

## 选题：JATS XML → PDF 智能排版

### 一、我们要做什么

把学术期刊的标准 JATS XML 数据文件，自动渲染成排版精美的 PDF 论文。

### 二、核心流水线（Pipeline）

```
┌──────────┐    ┌──────────┐    ┌──────────┐
│ JATS XML │ → │ 解析器   │ → │ 渲染器   │ → PDF
│ 输入文件 │    │ Parser   │    │ Renderer │   输出
└──────────┘    └──────────┘    └──────────┘
```

#### 第1步：解析 JATS XML
- 使用 `lxml` 库解析 XML
- 提取：标题、作者、摘要、关键词、章节结构、公式(MathML)、表格、参考文献
- 输出为结构化的 Python `Article` 对象

#### 第2步：渲染 HTML
- 使用 `Jinja2` 模板引擎
- 将 `Article` 对象 + HTML模板 → 完整HTML文档
- 公式使用 MathJax 渲染（在HTML中嵌入MathML/SVG）
- CSS Paged Media 控制排版

#### 第3步：生成 PDF
- 使用 `WeasyPrint` 将 HTML → PDF
- 支持：自动分页、页眉页脚、页码
- 支持单栏/双栏切换
- 嵌入字体和图片

### 三、技术选型理由

| 需求 | 方案 | 理由 |
|------|------|------|
| PDF生成 | WeasyPrint | Python原生，CSS排版灵活 |
| 模板 | Jinja2 | 最成熟的Python模板引擎 |
| XML解析 | lxml | 比标准库快10倍+，支持XPath |
| 公式 | MathJax + MathML | 保留原始语义，渲染质量高 |

### 四、难点与解决思路

#### 难点1：中文排版
- **问题**：WeasyPrint默认不支持中文换行规则
- **方案**：配置Noto Sans/Serif CJK字体，CSS中设置`word-break`和`text-align: justify`

#### 难点2：公式渲染
- **问题**：MathML到PDF的保真渲染
- **方案**：在HTML中用MathJax将MathML渲染为SVG，WeasyPrint保留SVG

#### 难点3：图表浮动定位
- **问题**：图表在图题附近自动定位，避免大片空白
- **方案**：CSS Paged Media的`float`属性和`page-break-inside: avoid`

#### 难点4：单/双栏切换
- **问题**：正文双栏、摘要单栏混排
- **方案**：CSS `column-count` 属性 + `column-span: all`

### 六、开发路线图

- [x] Phase 1: 基础流水线跑通（XML→PDF）
- [x] Phase 2: 完善章节结构（多级标题、子章节嵌套，扁平化为 .layout-main 直接子元素以支持双栏跨栏）
- [x] Phase 3: 公式渲染（MathML → mathjax-node 预渲染 SVG，块级+行内）
- [x] Phase 4: 图表排版（自动编号 图N/表N、题注、`<xref>` 可点击交叉引用）
- [x] Phase 5: 参考文献格式化（Elsevier + GB/T 7714，`--ref-style` 切换，悬挂缩进2em）
- [x] Phase 6: 双栏模式 + 页眉页脚（`--two-column`、`@page` running header + `counter(page)`、首页无页眉）
- [x] Phase 7: 中英双语摘要/关键词、机构上标、打印 pt 字号规范、42 项单元/集成测试
- [x] Phase 8: React 门户与文章工作台接入 FastAPI，在同一端口提供真实文章库、预览和 PDF 导出

### 七、运行环境与引擎

- **WeasyPrint（首选）**：原生 CSS Paged Media（`@page`/`column-count`/`page-break`）。macOS 无 Homebrew 时用 conda-forge 自带 GTK 的 weasyprint（无 sudo/brew）：`conda create -n jats2pdf --override-channels -c conda-forge python=3.12 weasyprint pango lxml jinja2 pytest`。
- **Chrome headless（回退）**：WeasyPrint 不可用时自动用系统 Chrome 打印 PDF（`pdf_renderer.py` 自动切换）。
- **公式预渲染**：mathjax-node（默认装于 `~/mjnode`，也可用 `JATS2PDF_MJDIR` 指定），`formula_renderer.py` 自举生成 `mathml2svg.js`。
- 详见 README.md「环境要求」「已知限制」。
