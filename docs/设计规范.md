### 纸张与版心
- **纸张**：A4（210×297mm）
- **Web 页边距**：上/下18mm，左/右19mm
- **门户默认布局**：双栏（CLI 仍可选择单栏或双栏）
- **双栏规则**：标题/作者/摘要/关键词通栏；正文双栏；图表和公式默认栏内，特殊宽表可单独设计通栏样式

## 二、字体规范（中英双语）

### 中文
| 元素 | 字体 | 大小 | 样式 |
|------|------|------|------|
| 论文标题 | **黑体 SimHei** | 16pt | 粗体 居中 |
| 副标题 | 黑体 | 12pt | 常规 居中 |
| 一级标题 | **黑体** | 12pt | 粗体 左对齐 |
| 二级标题 | **黑体** | 11pt | 粗体 左对齐 |
| 三级标题 | **黑体** | 10pt | 粗体 左对齐 |
| 摘要标题 | 黑体 | 10pt | 粗体 |
| 关键词标签 | 黑体 | 9.5pt | 粗体 |
| 正文 | **宋体 SimSun** | 10pt | 常规 两端对齐 |
| 图表题注 | 宋体 | 8.5pt | 常规 |
| 参考文献 | 宋体 | 8.5pt | 常规 |

### English
| Element | Font | Size | Style |
|---------|------|------|-------|
| Journal name | Times New Roman | 11pt | Italic |
| Author name | Times New Roman | 10pt | Regular |
| Running head | Times New Roman | 8pt | Italic |
| Body text (EN) | Times New Roman | 10pt | Justified |

### 字体重叠规则
```
中文优先:  黑体(标题) / 宋体(正文)
英文回退:  Times New Roman (衬线)
代码等宽:  Courier New (等宽)
```

## 四、表格规范 — 三线表

```
  ═══════════════════════════  ← 顶线 2px 粗
  表头1    表头2    表头3
  ───────────────────────────  ← 表头线 1px 细
  数据1    数据2    数据3
  数据4    数据5    数据6
  ═══════════════════════════  ← 底线 2px 粗
```

| 规则 | 说明 |
|------|------|
| 竖线 | **无** |
| 横线 | 仅顶线、表头线、底线 |
| 题注位置 | 表**上方** |
| 表注位置 | 表下方（如有） |
| 分页 | 不允许跨页 |

## 六、公式规范

| 规则 | 说明 |
|------|------|
| 输入格式 | MathML（优先）或 LaTeX |
| 渲染引擎 | MathJax 3.x → SVG |
| 对齐 | 居中 |
| 编号 | 右对齐，如 (1)、(2) |
| 行内公式 | $...$ 或 \(...\) |
| 块级公式 | $$...$$ 或 \[...\] |

## 七、参考文献 — Elsevier 格式

```
[1] Author A, Author B. Title of paper. Journal Name, 
    vol. 10, pp. 100-120 (2024).
[2] Author C. Another title. Another Journal, vol. 5, 
    pp. 50-60 (2023).
```

- **编号**：方括号 [1] [2] [3]
- **悬挂缩进**：2em（编号突出，正文缩进）
- **字体**：宋体 / Times New Roman，8.5pt
- **DOI 链接**：蓝色可点击

```
┌──────────────────────┐

│ ┌─────────┬─────────┐ │
│ │正文正文  │正文正文  │ │
│ │  图1     │正文正文  │ │ ← 图表默认栏内
│ │正文正文  │  表1     │ │
│ │正文正文  │正文正文  │ │
│ └─────────┴─────────┘ │
│ 参考文献继续双栏流排   │
└──────────────────────┘
```

## 十、赛题要求对照 ✅

| # | 赛题要求 | 实现方式 |
|---|---------|---------|
| 1 | 标题/作者/摘要/关键词正确渲染 | HTML模板渲染 |
| 2 | 章节结构 + 公式排版 | 递归section + MathJax |
| 3 | 图表自动定位 + 交叉引用 | CSS page-break + 超链接 |
| 4 | MathML公式高保真渲染 | MathJax SVG + 预渲染 |
| 5 | 参考文献格式化 | Elsevier格式模板 |
| 6 | 单栏/双栏灵活切换 | CSS class `two-column` |
| 7 | 页眉页脚页码自动生成 | CSS @page running headers |
