# 🎨 排版设计规范

> 参考期刊：Elsevier — *Expert Systems with Applications*
> 版本：v1.0

---

## 一、整体布局

```
┌──────────────────────────────────┐
│          A4 纸 (210×297mm)        │
│  ┌────────────────────────────┐  │
│  │      页边距 2cm             │  │
│  │                            │  │
│  │    【第一页】               │  │
│  │    期刊名（斜体小字）       │  │
│  │    论文标题（大号粗体居中）  │  │
│  │    作者（居中 + 上标编号）  │  │
│  │    ─────────────────────   │  │
│  │    ABSTRACT（缩进块）       │  │
│  │    Keywords                │  │
│  │    ─────────────────────   │  │
│  │    1. Introduction         │  │
│  │    正文正文正文正文...      │  │
│  │                            │  │
│  └────────────────────────────┘  │
└──────────────────────────────────┘
```

### 纸张
- **尺寸**：A4（210×297mm）
- **页边距**：上下 2cm，左右 2cm
- **栏数**：单栏

## 二、字体规范

| 元素 | 字体 | 大小 | 样式 |
|------|------|------|------|
| 论文标题 | Times New Roman / 黑体 | 16pt | **粗体**，居中 |
| 作者姓名 | Times New Roman / 宋体 | 10pt | 常规，居中 |
| 机构信息 | Times New Roman / 宋体 | 8pt | 常规 |
| 摘要标题 | Times New Roman / 黑体 | 10pt | **粗体** |
| 摘要正文 | Times New Roman / 宋体 | 9.5pt | 常规 |
| 关键词 | Times New Roman / 宋体 | 9.5pt | 常规 |
| 一级标题 | Times New Roman / 黑体 | 11pt | **粗体**，左对齐 |
| 二级标题 | Times New Roman / 黑体 | 10pt | **粗体**，左对齐 |
| 三级标题 | Times New Roman / 黑体 | 10pt | **粗体+斜体**，左对齐 |
| 正文 | Times New Roman / 宋体 | 10pt | 常规，两端对齐 |
| 表格内容 | Times New Roman / 宋体 | 8.5pt | 常规 |
| 图/表题注 | Times New Roman / 宋体 | 8.5pt | 常规 |
| 参考文献 | Times New Roman / 宋体 | 8.5pt | 常规 |
| 页眉页脚 | Times New Roman | 8pt | 斜体 |

---

## 三、间距规范

| 位置 | 间距 |
|------|------|
| 标题 ↔ 作者 | 0.8em |
| 作者 ↔ 摘要 | 2em |
| 摘要左右缩进 | 2em |
| 一级标题上方 | 1.8em |
| 二级标题上方 | 1.2em |
| 段落之间 | 0.4em |
| 行距（正文） | 1.6 倍 |

---

## 四、表格规范 — 三线表

```
  ─────────────────────  (顶线：2px 粗)
  表头1   表头2   表头3
  ─────────────────────  (表头线：1px 细)
  数据1   数据2   数据3
  数据4   数据5   数据6
  ─────────────────────  (底线：2px 粗)
```

- **只有横线，没有竖线**
- 顶线和底线用粗线（2px）
- 表头下用细线（1px）
- 题注放在表格**上方**
- 表注（如有）放在表格下方，8pt 灰色

---

## 五、图表规范

| 规则 | 说明 |
|------|------|
| 图题位置 | 图的下方 |
| 表题位置 | 表的上方 |
| 题注编号 | Fig. 1. / Table 1 |
| 居中 | 图表本身居中 |
| 分页 | 图表不允许跨页断开 |

---

## 六、参考文献格式

```
[1] Author A, Author B. Paper title. Journal Name, 
    vol. 10, pp. 100-120, 2024.
[2] Author C. Another paper title. Another Journal, 
    vol. 5, pp. 50-60, 2023.
```

- **编号**：方括号 [1] [2] [3]
- **悬挂缩进**：第二行起缩进 1.5em
- 字体大小：8.5pt

---

## 七、页眉页脚

| 位置 | 内容 | 字体 |
|------|------|------|
| 左上 | 期刊名（斜体） | 8pt |
| 右上 | 页码 | 8pt |
| 首页 | 不显示页眉 | — |
